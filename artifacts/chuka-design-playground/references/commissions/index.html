How the work runs

A Renaissance workshop kept every stage of a painting under one roof, from grinding pigment to the final varnish. I work the same way: one person carrying a project from the first question to the finished result.

  1. Diagnose

    Read the market, the data and the incentives. Name the one constraint that matters.

  2. Design

    Decide who owns what, how the work flows, and which numbers to watch each week.

  3. Build

    Ship the product, the process or the system, and put it in front of real customers.

  4. Result

    Measure it, learn from it, and make it repeatable.
