# Plate experience draft

An isolated, noindex direction experiment. It is an alternative to Underdrawing. The site uses monumental League Gothic, gallery whitespace, untouched colour paintings and natural historical engravings. Nothing here changes the production app, account, domain, DNS or main branch.

## Run and delivery

Install with `npm ci`, run `npm run build`, then `npm run check`. This project deliberately has no dev-server script. Preview and browser QA use its isolated Cloudflare Worker `chuka-plate-lab` after GitHub push and Major web preflight. Deploy with a source commit bound through `DEPLOY_SHA`. The Worker serves only `dist`, marks every response noindex and disallows crawling through robots.txt.

## What to try

- Enter the six gallery plates and open their real inner pages.
- Follow the chapter links and the breadcrumbs to the practice and footer.
- Turn the printed geometric solid with the pointer or the Turn button.
- Grab print handles, move with arrow keys, or arrange the table again. Shift increases the keyboard step; Home restores the initial arrangement.
- Pick up the chalk, draw, put it down, or use Draw a line and Clear with the keyboard.

Essential work, résumé and contact remain directly accessible. There are no access gates, fake countdowns, automatic audio or blocking preloaders. The footer object is optional. Three.js loads when its area approaches the viewport and renders on input rather than spinning continuously. Reduced motion uses immediate state changes. Historical geometry remains visible if WebGL is unavailable.

## Prior art decision

ADOPT Astro 7.3.5 for a static document per route, GSAP 3.15.0 for scoped motion, and Three.js 0.186.1 for the bounded geometry object. Versions were checked against the npm registry on 3 October 2026. Use Astro’s native bundled scripts, native pointer events, ResizeObserver and CSS rather than adding a framework, physics package or scroll library. The shared case template produces all six routes.

BORROW composition and pacing from the owner’s Plate/Newcastle references. BORROW optional social play and a chalk space from Wiredge, without copying its brand, assets or complex physics. The primary X reference was inspected by the controller: fine etched city and classical imagery with cream and selective muted teal. Its still images guide material treatment; they do not establish a demonstrated motion effect.

The focused check covers route and asset completeness, natural imagery, noindex, semantic headings, key controls, case integrity and bounded poster geometry. The controller owns rendered browser, responsive and adversarial review evidence.
